# Credit Card Customer & Transaction Analysis - Power BI

A two-page interactive Power BI dashboard analyzing credit card customer behavior and transaction trends.

## Dashboard Pages
- **CC Customer Report** - Customer segmentation by age, income, job, state, education
- **CC Transaction Report** - Revenue by expenditure type, chip type, card category, loan purpose

## Data Model
- Two tables joined on `client_num` — customer details and card transaction details

## Key KPIs
| Metric | Value |
|--------|-------|
| Total Revenue | 1M |
| Total Interest | 151.7K |
| Total Amount | 865.3K |
| Transaction Count | 12.6K |

## Key Insights
- Businessmen generated highest revenue ($0.35M)
- Blue card category dominates with $0.89M revenue
- Swipe transactions account for 73% of revenue
- Graduate customers contribute highest revenue ($0.43M)

## Tech Stack
Power BI, DAX, Excel
